# Freelancer Amit website

Static multipage website (HTML, CSS, JavaScript). No build step needed.

## Deploy on GitHub Pages
1. Create a new GitHub repository and upload everything in this folder (keep `index.html` at the root).
2. Go to Settings > Pages, set Source to "Deploy from a branch", choose `main` and `/ (root)`, then Save.
3. Your site goes live at `https://<username>.github.io/<repo>/` in a minute or two.

## Edit content
All page text lives in `assets/app.js`. Colours and animations are in `assets/style.css`.
